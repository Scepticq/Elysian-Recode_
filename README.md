Установка
Скачай `Elysian_Recode.lua` (и при необходимости `preset.json` / `config.json`)
Положи lua в папку скриптов Neverlose
В меню NL: Scripts → Load → выбери Elysian Recode
Настрой вкладки Visuals / AA / Misc под себя
Файлы для сайта (GitHub Pages):
```text
index.html
files/
  Elysian_Recode.lua
  preset.json
  config.json
```
